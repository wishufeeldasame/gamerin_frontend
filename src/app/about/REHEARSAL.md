# GamerIN 소개 페이지 검증

기존 `/demo` 소개 페이지를 `/about`으로 이동했다. 아래 촬영·수치는 이동 전 검증 이력이며 새 전시용 `/demo`와 구분한다.

이동 후 `npm run build`, `npx playwright test e2e/about.spec.ts --workers=2`(13개), 재생 시계 Vitest(3개)를 다시 통과했다. 전시 페이지 추가 전 중간 커밋의 `/demo`는 `/about`으로 임시 연결한다.

## 구성과 출처

- 공개 경로: `/about`. 기존 `/` 피드와 `(app)` 셸은 변경하지 않았다.
- Gold: `hero-demo`의 창 크기·하단 크롭, `loading`의 갱신 피드백, `share`의 측정 기반 팝오버, `ai-cards`의 선택·확정, `messages`의 입력·전송·읽음 흐름을 참고했다. 예제 사본은 작업용 임시 디렉터리에 두었다.
- 원본 제품 이름·색·콘텐츠 대신 GamerIN의 로고, 디자인 토큰, 게임·티어 이미지, 한국어 예시 데이터를 사용했다. iMessage 기기 UI는 복제하지 않았다.
- 모바일은 프로필의 전적 부분, 선택한 게시물, 프로그램, 대화에 집중하는 별도 구도다. 데스크톱 화면 전체를 축소하지 않는다.
- 각 장면은 화면 진입 시 한 번 재생하고 완료 결과를 유지한다. 재생 중 화면 밖으로 나가면 미완료 장면은 초기화된다. 반복은 사용자의 `다시 보기`로만 시작한다.
- 장면 내부는 `inert`·`aria-hidden`으로 실제 조작 및 탭 순서에서 제외했다. 장면 설명과 재생·정지·다시 보기 버튼은 별도로 제공한다.

## 장면과 결과 프레임

| 장면 | 동작 | 완료 결과 |
| --- | --- | --- |
| 전적 프로필 | 새로고침, 전적 감쇠, 로딩 안내, 갱신 | 다이아몬드 II·승률 62%·KDA 4.28·방금 업데이트됨 |
| 피드 | 저장, 컬렉션 팝오버, 컬렉션 선택 | 컬렉션 선택 체크와 저장 확인 |
| 멘토링 | 게임 필터, 프로그램 상세, 신청 | 신청 접수와 멘토 수락 대기 |
| DM | 기존 대화, 입력, 전송, 읽음 | 새 말풍선과 읽음 확인 |

`prefers-reduced-motion`에서는 위 결과를 정적으로 표시한다. 실사용자·실전적·실결제 데이터는 없다.

## 자동 검증

- `npm run build`: 성공. `/demo` 정적 페이지 생성, 페이지 크기 2.94 kB / First Load JS 115 kB. 데모 장면 코드는 동적 로딩이므로 이 수치는 후속 장면 청크를 포함하지 않는다.
- `npx playwright test e2e/demo.spec.ts --workers=2`: 프로덕션 빌드에서 13개 성공.
  - 1440·768·390·320px, 다크·라이트, 줄어든 모션의 결과·가로 넘침 검사.
  - 1440·390px에서 재생, 입력 중 정지, CSS 애니메이션 정지, 재개, 다시 보기, 완료 후 화면 재진입 검사.
  - 키보드, 내부 가짜 컨트롤의 탭 제외, 재생 중 모션 설정·화면 크기 변경 검사.
  - 게스트의 도메인 API 호출 0건, 세션 복원 장애에서도 데모 표시 검사.
  - 세션 장애 fixture만 `bypassCSP`를 사용한다. 로컬 프로덕션 3000의 기존 8080 API 경로를 503 mock으로 검증하기 위한 테스트 설정이며 앱 CSP는 변경하지 않았다. 다른 접근·레이아웃·재생 테스트는 실제 CSP를 유지한다.
- `npm test -- --exclude '.claude/**'`: 현재 저장소 107개 파일, 1,213개 테스트 성공. 신규 재생 시계 테스트 3개 포함.
- `npx eslint src/app/demo e2e/demo.spec.ts src/components/stageshow/kit/playback.ts src/components/stageshow/index.ts`: 성공.
- `npm run lint -- --ignore-pattern '.claude/**'`: 오류 없음, 원본 kit 및 기존 문서 캡처 코드의 경고 9개. 원본 kit의 일반 이미지·미사용 기기 컴포넌트 등은 이번 데모 때문에 리팩터링하지 않았다.
- `npx tsc --noEmit`: 성공.
- `npm run lint`, 제외 없이 실행한 `npm test`: 기존 `.claude/worktrees/representative-tier/`의 다른 작업 트리와 생성 파일까지 포함해 실패했다. 해당 파일은 변경하지 않았다.
- `git diff --check` 및 신규 파일 별도 공백 검사: 성공.
- `class-clash.mjs`: CSS 네임스페이스 겹침 없음.
- 데스크톱·모바일 `layout.mjs --strict`: `no-issues-detected`. 박스 검사이며 시각 승인으로 간주하지 않는다.

개발 서버와 빌드를 동시에 실행한 첫 빌드는 `.next` 산출물 충돌로 실패했다. 개발 서버를 중지한 뒤 독립 실행한 빌드는 성공했다.

작업 재개 시 이전 프로덕션 미리보기가 교체된 빌드의 JS 청크를 요청해 13개 E2E가 클라이언트 예외로 실패했다. 작업자가 띄운 미리보기만 재시작한 뒤 같은 13개가 다시 모두 성공했다. 재개 후 신규 재생 시계 테스트 3개와 데모 범위 ESLint도 다시 통과했다. 그사이 추가된 멤버십 관련 사용자 변경은 수정하지 않았고, 해당 변경까지 포함하는 전체 빌드·전체 테스트는 다시 실행하지 않았다.

## 시각 리뷰와 반영

독립 fresh-eye 리뷰의 첫 발견 6건을 반영했다. 결과 파일은 작업용 디렉터리의 `visual-review.md`다.

| 발견 | 반영 |
| --- | --- |
| 모바일 저장 팝오버가 게시물을 가림 | 저장 후 팝오버를 닫고 하단 Toast로 확인. poster에 게시물 제목·게임 그림·저장 상태를 남김. 결과와 게임 그림이 겹치지 않는 E2E 검사 추가 |
| 프로필 오른쪽 빈 패널 | 보조 패널·회색 막대 제거. 전적 카드를 전체 폭으로 배치하고 hero 높이 축소 |
| DM의 빈 사이드바 | 데스크톱 대화 목록 제거, 대화 중심의 낮은 프레임으로 재구성 |
| 말풍선 도착 전 전송 상태 노출 | 전송과 전달 상태를 분리. 말풍선 인계 800ms 뒤 전달 상태 표시. `sent` 시점에는 상태가 숨겨진다는 E2E 검사 추가 |
| 라이트 수신 말풍선이 흐림 | 기존 중립 표면 토큰으로 수신 말풍선 구분 |
| 헤더 아바타 글자 치우침 | 자막 CSS를 실제 자막에만 한정해 kit 아바타 정렬·흰 글자 복원 |

수정 후 포스터·전체 페이지·상태 시트를 재촬영했다. 최종 독립 재검토는 사용량 제한 오류로 중단됐으며 완료 결과 파일은 없다. 작업자가 최신 전적·피드·멘토링·라이트 DM 포스터, hero, 50ms 전송 인계 시트를 직접 확인했다. 이를 독립 리뷰 승인으로 간주하지 않는다. 최종 독립 재검토와 sampling gap이 있는 연속 모션은 미확정으로 남긴다.

촬영 도구는 skill 원본을 수정하지 않고 임시 복사본을 사용했다. Next가 여러 CSS를 한 파일로 합치므로 `kit override` 검사에서 **원본 kit의 `@layer stageshow`만** 구분하도록 맞췄다. 데모의 레이어 밖 CSS 검사는 유지했다. `--host-theme`는 기존 사용자 테마 설정을 localStorage에 주입하는 촬영용 옵션이다.

## kit 변경

`src/components/stageshow/`에 MIT 라이선스·고지와 kit를 보존했다. `index.ts`는 사용하는 컴포넌트만 내보내 불필요한 기기·브랜드 CSS 로딩을 피한다.

- `kit/playback.ts`: 전역 타이머를 교체하지 않는 장면별 정지·재개 시계.
- `kit/act.ts`, `stage.tsx`: 장면 시계 연결과 해당 장면의 CSS 애니메이션 정지.
- `kit/motion/Roll.tsx`, `Collapse.tsx`: 정지 중 텍스트·표면의 후속 정리 타이머도 보존.
- `kit/controls/Field.tsx`: 입력 글자 자체를 측정하고 실제 타이핑임을 기록할 `text` 속성 제공. 필드 전체를 순간 전환으로 예외 처리하지 않는다.
- `kit/clock.ts`: 원본 브라우저 타이머 교체 코드의 타입 lint 예외만 명시. 데모 런타임은 이 전역 가상 시계를 설치하지 않는다.

## 운영 경계와 미검증

- 데모 장면은 실제 API·SSE·스토어를 호출하지 않는다. 루트 인증·북마크 Provider는 기존대로 동작하므로 저장된 세션이 있으면 인증 복원·북마크 조회가 발생할 수 있다.
- 백엔드, DB, Docker, 비밀 설정, 실결제·실계정은 변경하거나 조작하지 않았다.
- 실기기 iOS·Android, Safari·Firefox, 실제 게임사·결제·SSE 연동은 검증하지 않았다.
- 배포·커밋·PR은 하지 않았다. PR을 만들 때 관련 `docs/` 소개 경로·프론트 구조 문서 현행화가 필요하다.
