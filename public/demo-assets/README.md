# 전시용 발로란트 자료

`/demo` 전시 소개 화면(`src/app/demo`)이 쓰는 정적 자료다.

- 원본: 사용자가 제공한 `vlrt_movie.mp4` (1920×1080, 약 10.63초). 저장소에는 넣지 않았다.
- `valorant-highlight.mp4`: 원본 2–10초의 8초 구간. 1280×720 MP4, 오디오 트랙 제외. 피드 게시물과 메시지 첨부 장면에서 무음 반복 재생한다.
- `valorant-thumb-2.jpg`: 원본 약 4.8초의 1280px JPEG 프레임. 영상 포스터와 첨부 미리보기에 쓴다.
- macOS AVFoundation의 `AVAssetExportSession`과 `AVAssetImageGenerator`로 추출했다. 앱 런타임에서 변환하지 않는다.
- 파일은 공개 정적 경로로 제공된다. 원본 영상의 전시·배포 권한은 제공자가 확인해야 하며 프로젝트 라이선스가 영상 권리를 부여하지 않는다.
- 화면의 계정·전적·게시물·멘토링·메시지는 모두 예시이며 서버 요청을 보내지 않는다.
